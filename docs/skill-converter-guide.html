Universal Agent Skill Converter

Convert agent skills from Anthropic Claude Code, GitHub Copilot CLI, Amp, Cursor, and Cline into 100% native, progressive-disclosure Google Antigravity skills.

The 4-Stage Conversion Pipeline

1

Frontmatter Ingestion

Normalizes YAML headers, strips host-specific flags (allowed-tools:), and crafts high-citability third-person trigger descriptions.

2

Tool Translation

Replaces external commands (Bash, View, Edit, Write) with native Antigravity primitives using single-pass token regex.

3

Progressive Partitioning

Extracts heavy reference documentation and sub-manuals into references/, keeping SKILL.md lean to conserve model context.

4

Asset Bundling

Recursively mirrors helper scripts, test suites, and schema templates into standard scripts/, examples/, and resources/.

In-Chat Conversational Invocations

Antigravity dynamically indexes skill-converter. Trigger it naturally in any conversation:

agy, convert the claude skill at "C:\path\to\skill" to antigravity
agy, port my copilot skill in .github/skills/deploy to antigravity
agy, migrate all skills in ~/.claude/skills into ~/.agents/skills

Direct Command-Line Usage (CLI)

The core migration engine convert_skill.py runs in any terminal without external dependencies:

python scripts/convert_skill.py "path/to/source-skill"
python scripts/convert_skill.py "path/to/skills-root" --batch -o "~/.agents/skills"
python scripts/convert_skill.py "path/to/source-skill" --dry-run

Tool Mapping Crosswalk

Automated replacement mapping from external agent tools to Antigravity primitives:

Source Agent Tool Antigravity Native Tool Operational Rules & Differences
Bash / execute_command run_command Executes via PowerShell; accepts CommandLine, Cwd, and WaitMsBeforeAsync. Never issues cd.
View / Read / read_file view_file Requires absolute path; supports line range slicing (StartLine, EndLine) to protect context.
Edit / replace_in_file replace_file_content Surgical line-range replacement. Exact matching inside specified bounds prevents collateral edits.
Write / write_to_file write_to_file Writes whole files; omits ArtifactMetadata for workspace source files.
Grep / search_files grep_search Blazing fast ripgrep searching across files with glob filters.
Glob / file_search find_by_name High-performance file/directory pattern resolution using fd.
AskUser ask_question Interactive multi-choice modal rendered directly inside the chat UI canvas.
$ARGUMENTS <user-arguments> Transpiled into semantic argument parsing guidance for the model.
